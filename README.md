# 🗄️ SQL Practice

A structured and practical **SQL learning and practice repository** designed for beginners, students, self-learners, developers, data analysts, and anyone preparing for SQL interviews.

This repository takes you from **SQL fundamentals to advanced concepts**, with explanations, examples, practice problems, solutions, challenges, interview questions, and real-world projects.

---

## 🎯 Repository Goals

The goal of this repository is to provide a complete, hands-on SQL learning path that helps you:

* Understand SQL fundamentals
* Learn how relational databases work
* Write SQL queries confidently
* Practice SQL problems progressively
* Understand database design concepts
* Master joins, subqueries, CTEs, and window functions
* Prepare for SQL interviews
* Build real-world SQL projects
* Develop problem-solving skills using SQL

---

## 🛠️ SQL Dialect

This repository primarily uses:

**MySQL 8.0+**

Examples and exercises are written using MySQL-compatible SQL syntax.

> Some SQL features differ between MySQL, PostgreSQL, SQL Server, and other database systems. When relevant, those differences will be mentioned in the notes.

## 📂 Module Structure

Most learning modules follow the same structure:

```text
01_sql_basics/
│
├── notes.md
├── examples.sql
├── practice.sql
├── solutions.sql
└── challenge.sql
```

### 📘 `notes.md`

Contains explanations of the topic, syntax, important concepts, and common mistakes.

### 💻 `examples.sql`

Contains commented SQL examples demonstrating the concepts.

### 📝 `practice.sql`

Contains exercises for practicing the topic.

### ✅ `solutions.sql`

Contains solutions to the practice exercises.

Try solving the questions yourself before looking at the solutions.

### 🚀 `challenge.sql`

Contains more challenging problems designed to improve SQL problem-solving skills.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/sql-practice.git
```

### 2. Navigate to the Repository

```bash
cd sql-practice
```

### 3. Install MySQL

Install **MySQL 8.0 or later** on your computer.

### 4. Open MySQL

You can use MySQL through:

* MySQL Command Line Client
* MySQL Workbench
* VS Code with a SQL extension
* Another MySQL-compatible database tool

### 5. Start Practicing

Navigate to any module:

```text
01_sql_basics/
```

Read the notes, study the examples, solve the practice problems, and then check your answers against the solutions.

## 🧪 Recommended Learning Method

For the best results, follow this cycle:

```text
Learn
  ↓
Read the Notes
  ↓
Study the Examples
  ↓
Write Queries Yourself
  ↓
Solve Practice Problems
  ↓
Check Solutions
  ↓
Attempt the Challenge
  ↓
Build Projects
```

Avoid simply copying the solutions.

The goal is to develop the ability to **think in SQL** and solve problems independently.
