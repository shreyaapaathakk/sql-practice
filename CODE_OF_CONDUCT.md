# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming, respectful, and positive experience for everyone.

We expect contributors, maintainers, and community members to communicate respectfully and constructively.

---

## Expected Behavior

Examples of positive behavior include:

- Being respectful and considerate.
- Providing constructive feedback.
- Welcoming beginners and new contributors.
- Respecting different opinions and approaches.
- Focusing discussions on improving the project.
- Helping others learn and improve.
- Accepting constructive criticism gracefully.

---

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks or insults.
- Trolling or deliberately disruptive behavior.
- Threats or intimidation.
- Publishing someone's private information without permission.
- Sexual or inappropriate comments.
- Deliberately offensive or hostile communication.
- Any other behavior that creates an unsafe or unwelcoming environment.

---

## Maintaining a Learning-Friendly Environment

This repository is intended to support people who are learning SQL.

Contributors should feel comfortable:

- Asking beginner questions.
- Making mistakes.
- Requesting clarification.
- Suggesting alternative solutions.
- Discussing different SQL approaches.

Different valid SQL solutions may exist for the same problem. Discussions should focus on understanding and improving the solution rather than dismissing alternative approaches.

---

## Reporting Problems

If you experience or observe unacceptable behavior, please report it to the repository maintainer through the appropriate GitHub communication channel.

Reports should include enough information to understand what happened.

All reports will be reviewed appropriately.

---

## Enforcement

Project maintainers may take appropriate action when behavior violates this Code of Conduct.

Possible actions include:

- Asking someone to stop inappropriate behavior.
- Removing inappropriate content.
- Closing discussions or issues.
- Rejecting contributions that violate these guidelines.
- Restricting participation when necessary.

The goal of enforcement is to maintain a respectful and productive learning environment.

---

## Scope

This Code of Conduct applies to project spaces, GitHub issues, pull requests, discussions, and other interactions directly associated with this repository.

---

## Final Note

SQL Practice is intended to be a place where people can learn, practice, contribute, and improve together.

Be respectful. Be curious. Keep learning. 🚀
