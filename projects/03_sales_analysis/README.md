# Sales Analysis

A practical MySQL 8.0+ project designed to analyze sales data and answer common business questions using SQL.

This project simulates a retail sales system containing customers, products, categories, sales orders, and order items. It is designed to demonstrate how SQL can be used for business intelligence, reporting, and decision-making.

## Project Objectives

The main objectives of this project are to:

- Analyze total sales revenue
- Measure order and product performance
- Identify top-selling products
- Identify the most profitable categories
- Analyze customer purchasing behavior
- Calculate average order value
- Analyze monthly sales trends
- Compare sales performance across regions
- Identify repeat customers
- Calculate customer lifetime value
- Rank customers and products
- Analyze month-over-month sales growth
- Practice CTEs and window functions
- Build portfolio-ready SQL analysis queries

## Database Structure

The project contains the following tables:

### `categories`

Stores product categories.

### `products`

Stores products available for sale.

### `customers`

Stores customer information.

### `sales_orders`

Stores order-level information such as customer, order date, region, and status.

### `sales_order_items`

Stores individual products included in each order.

The relationship between orders and products is many-to-many, so `sales_order_items` acts as the bridge table.

## Database Relationships

```text
categories

````

## Key Business Metrics

This project calculates several important sales metrics.

### Total Revenue

```text
Total Revenue = SUM(quantity × unit_price × (1 - discount))
```

### Total Units Sold

```text
Total Units Sold = SUM(quantity)
```

### Average Order Value

```text
AOV = Total Revenue / Number of Orders
```

### Customer Lifetime Value

For this project, customer lifetime value is represented by the total revenue generated by a customer.

```text
CLV = SUM(customer order revenue)
```
